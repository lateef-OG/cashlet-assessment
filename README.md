# Cashlet React Native Assessment

This project is a **React Native mobile application** built as part of a technical assessment.  
It demonstrates UI composition, basic state management, and a custom animated Snackbar component.

---

## Features

- Displays a list of user goals using `FlatList`
- Reusable `GoalCard` component
- Custom global **Snackbar**
  - Animates in from the top
  - Auto-dismisses after a configurable duration
  - Can be dismissed manually
  - Supports text update on press

---

## Tech Stack

- React Native (CLI)
- Functional components & React Hooks
- `Animated` API
- Flexbox layout
- TypeScript

---

## Running the App

> Ensure your environment is set up:  
> https://reactnative.dev/docs/set-up-your-environment

### Start Metro

```sh
npm start
# or
yarn start
```

### Android

```sh
npm run android
# or
yarn android
```

### iOS

```sh
bundle install
bundle exec pod install

npm run ios
# or
yarn ios
```
